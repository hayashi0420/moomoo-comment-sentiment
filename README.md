# moomoo センチメント温度計 Skill

moomoo プラットフォーム上のコミュニティ・フィード投稿を集計し、低品質投稿をフィルタリングした上で、強気 (Bullish) / 弱気 (Bearish) / 中立 (Neutral) のセンチメント分類を行い、構造化されたセンチメントスナップショットを出力する Claude Code 用 Skill です。

## 機能概要

- 指定した銘柄(1 件または複数件)に対して、リアルタイムのコミュニティ投稿を取得
- 低品質投稿の自動フィルタリング
- 投稿内容のセンチメント分類(強気 / 弱気 / 中立)
- 構造化された JSON 形式でスナップショットを返却
- 複数銘柄指定でポートフォリオ全体のセンチメント一括取得にも対応

## 想定ユースケース

- 特定銘柄のコミュニティの盛り上がり状況を確認したい
- 複数銘柄のポートフォリオ・センチメントを一括取得したい
- 個人投資家の強気・弱気ムードを把握したい
- moomoo コミュニティ上の話題の傾向を分析したい

## 必要環境

- Claude Code CLI または Claude Agent SDK
- moomoo OpenAPI 認証設定済み環境
- curl / openssl / date コマンド(Linux・macOS 標準搭載、Windows は Git Bash 推奨)
